# TigerConnect Adoption Dashboard

Static single-page dashboard published at [www.medicalstaffnews.com](https://www.medicalstaffnews.com)
via GitHub Pages (branch `main`, folder `/`). There is no build step and no dependencies —
`index.html` is fully self-contained.

## Files

| File                  | Purpose                                                              |
| :-------------------- | :------------------------------------------------------------------- |
| `index.html`          | The published dashboard. Snapshot data is inlined; open it directly. |
| `index_template.html` | Source template with an empty data placeholder.                      |
| `_embed.json`         | The snapshot data that gets inlined into the template.               |

## Regenerating with a new snapshot

`index_template.html` contains, on line 214:

```js
const DATA = /*__DATA__*/{}/*__END__*/;
```

Replace the `{}` between those two markers with the full contents of `_embed.json`,
and write the result to `index.html`:

```bash
python3 - <<'EOF'
import re
tpl = open('index_template.html').read()
data = open('_embed.json').read().strip()
out = re.sub(r'/\*__DATA__\*/.*?/\*__END__\*/', '/*__DATA__*/' + data + '/*__END__*/', tpl, flags=re.S)
open('index.html', 'w').write(out)
EOF
```

This keeps the `/*__DATA__*/` … `/*__END__*/` markers in the output, so the generated
`index.html` can itself be re-run through the same script. (The currently committed
`index.html` was generated by an earlier tool that stripped the markers — same data,
just not re-runnable.)

Verify by opening `index.html` in a browser — the snapshot date in the header should
match the `snapshot` field in `_embed.json`.
